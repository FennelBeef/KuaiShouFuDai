# KuaiShouFuDdai

用于单个快手直播间实现持续抢福袋的自动化过程

现已具备：

- adb控制
- OCR识别
- 图像模板匹配
- 状态判断
- 自动点击
- 中奖结果判断

需要依赖：

- adbutils
- paddleocr
- cv2

电脑端需安装abd环境：

- platform-tools
 https://developer.android.google.cn/tools/releases/platform-tools?hl=zh-cn
